Télécharger Calc For All

Application Android (APK). Compilation via GitHub Actions.

Voir le projet GitHub Télécharger l’APK (Actions)
  1. Ouvre le dépôt GitHub de l’application
  2. Va dans l’onglet Actions
  3. Lance le workflow Build APK
  4. Télécharge l’artefact une fois le build terminé
  5. Installe l’APK sur ton téléphone Android

Questions fréquentes

L’application est-elle gratuite ?

Oui, le projet est open-source et gratuit.

Faut-il internet pour l’utiliser ?

Non. Une fois installée, l’application fonctionne entièrement hors ligne.

Y a-t-il une version iOS ?

Pour le moment seule la version Android (APK) est disponible. Une version iOS nécessite un compte développeur Apple.

Comment obtenir les mises à jour ?

Relance simplement le workflow GitHub Actions pour générer un nouvel APK avec les dernières fonctionnalités.
